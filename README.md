## Deployment

### Podman Compose

```yaml
services:
  n8n:
    image: ghcr.io/daemonless/n8n:latest
    container_name: n8n
    environment:
      - N8N_ENCRYPTION_KEY=your-encryption-key-here
      - PUID=1000
      - PGID=1000
      - TZ=UTC
    volumes:
      - "/path/to/containers/n8n:/config"
    ports:

    restart: unless-stopped
```
